## Constats documentaires

Sources officielles consultées le 05/10 ; pages évolutives à revalider lors du
choix d'une version. Il s'agit de lecture, pas de benchmarks exécutés.

| Point | Constat et conséquence |
| --- | --- |
| Architecture | NVIDIA classe la V100 en compute capability 7.0 [1]. Vérifier le support Volta du moteur et des kernels réellement employés. |
| Variante matérielle | La fiche NVIDIA distingue V100 PCIe et V100 SXM2 avec interfaces différentes [2]. Toytoy précise SXM2 sur adaptateur PCIe ; les caractéristiques de cet adaptateur et son câblage NVLink restent à relever. |
| Ollama | Sa liste matérielle inclut la V100 [3]. Cela permet de le garder candidat ; cela ne qualifie ni un modèle, ni les performances à deux GPU. |
| Placement Ollama | La FAQ décrit un chargement sur un seul GPU quand le modèle y tient, sinon une répartition sur les GPU disponibles [4]. Vérifier le placement observé et l'usage réel de l'interconnexion. |
| vLLM | Le prérequis NVIDIA publié actuellement est compute capability 7.5+ [5]. **Déduction** : la V100 7.0 n'entre pas dans ce support standard ; aucune recommandation automatique de remplacement par vLLM. |
| llama.cpp serveur | Candidat à comparer ; vérifier une version, la compilation CUDA, les kernels et le partage disponibles [6]. Aucune performance ou configuration Volta qualifiée dans cette session. |
