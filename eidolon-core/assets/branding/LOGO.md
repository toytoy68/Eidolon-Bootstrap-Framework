# Logo officiel du programme Eidolon

Statut : **ADOPTÉ**, décision de toytoy le 08/10/2026 vers 16 h 09,
publication et validation comme logo programme demandées vers 16 h 10 (Europe/Paris).

![Logo officiel Eidolon](eidolon-logo.png)

Identité : **Eidolon Core Technologies (ECT)**.
Composition adoptée : grand **e minuscule manuscrit**, mot IDOLON à sa droite,
orbite bleue et signature **Core Technologies**, fond bleu nuit, reflets bleu roi/cyan.
Les variantes E majuscule géométrique, Internet Explorer et E majuscule manuscrit
étaient des explorations ; la variante minuscule manuscrite est le logo retenu.

## Fichier canonique

`eidolon-logo.png` : original PNG généré dans ChatGPT, 1672 × 941 pixels,
conservé à l'identique. Empreinte blob Git : `b1369993049a2810a640a68e7423b442da66036d`.
Ce fichier est la référence officielle pour le logo du programme.

L'icône Desktop déjà validée est conservée dans `eidolon-icon-reference.png`.
Cette décision sur le logo ne remplace pas automatiquement l'icône Windows.
Les déclinaisons transparentes, vectorielles, monochromes et les raccordements
aux interfaces pourront être réalisés dans des lots dédiés à partir de cette référence.
La publication de l'asset ne signifie pas que l'application l'affiche déjà.
