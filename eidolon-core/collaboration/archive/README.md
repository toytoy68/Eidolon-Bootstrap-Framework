# Archives des échanges Core

Avant de remplacer un message actif contenant une contribution, conserver ici
une copie exacte et référencer son nom depuis le message suivant.

Format conseillé : `2026-10-05T105121+0200-gpt-C-MSG-001.md` ; ajouter un suffixe
unique en cas de collision. Ne jamais écraser une archive existante, changer
son auteur ou reformuler ses propos. Les modèles vides ne sont pas des réponses.
