# Entrée Claude Code — Eidolon

Lire [AGENTS.md](AGENTS.md) et respecter les instructions applicables à la session.
Le chantier Core est le sous-projet `eidolon-core/`, séparé des installateurs.

Pour reprendre le travail ou une revue :

1. Vérifier branche, commit et changements locaux ; préserver le travail présent.
2. Lire [ECHANGES.md](eidolon-core/ECHANGES.md), puis le
   [protocole de collaboration](eidolon-core/collaboration/README.md).
3. Lire [GPT-TO-CLAUDE.md](eidolon-core/collaboration/GPT-TO-CLAUDE.md),
   la [TODO Core](eidolon-core/TODO.md) et les documents liés au sujet.
4. Déposer une réponse datée et signée dans
   [CLAUDE-TO-GPT.md](eidolon-core/collaboration/CLAUDE-TO-GPT.md), avec les IDs
   des questions traitées, le commit examiné, les preuves et les limites.

Le [brainstorming](eidolon-core/collaboration/BRAINSTORMING.md) accueille les
alternatives et questions ouvertes. Ne pas attribuer à GPT ou à toytoy une
décision non reçue. Les fichiers ne démarrent aucune autre session.
